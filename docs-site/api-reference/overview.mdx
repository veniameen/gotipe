# API Reference

GoTipe Cloud provides a REST API for document management, collaboration, AI, and exports.

## Authentication

All API requests require authentication via Bearer token:

```bash
curl https://api.gotipe.com/v1/documents \
  -H "Authorization: Bearer gt_live_sk_..."
```

Two authentication methods are supported:

- **API Keys** — Long-lived keys for server-to-server communication. Format: `gt_live_sk_<32hex>`
- **JWT Tokens** — Short-lived tokens for client-side use. Generated via `/auth/token` endpoint.

## Base URL

| Environment | URL |
|------------|-----|
| Production | `https://api.gotipe.com/v1` |
| Development | `http://localhost:8080/v1` |

## Error Format

All errors follow a consistent format:

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Document not found",
    "details": {}
  }
}
```

## Rate Limits

Rate limits use sliding window counters. When rate limited, the response includes a `Retry-After` header.

| Plan | Requests/min | AI requests/day |
|------|-------------|----------------|
| Starter | 60 | 100 |
| Pro | 300 | 1000 |
| Business | 1000 | Unlimited |

## Endpoints

### Documents

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/documents` | List documents |
| `POST` | `/documents` | Create document |
| `GET` | `/documents/:id` | Get document |
| `PATCH` | `/documents/:id` | Update document metadata |
| `DELETE` | `/documents/:id` | Delete document |
| `POST` | `/documents/:id/export` | Export document |

### Collaboration

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/documents/:id/sessions` | List active sessions |
| `POST` | `/documents/:id/token` | Generate WebSocket token |
| `WS` | `/sync/:id` | WebSocket sync endpoint |

### AI

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/ai/complete` | Inline completion |
| `POST` | `/ai/transform` | Transform selection |
| `POST` | `/ai/summarize` | Summarize document |

### Versions

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/documents/:id/versions` | List versions |
| `POST` | `/documents/:id/versions` | Create version |
| `GET` | `/documents/:id/versions/:vid` | Get version |
| `POST` | `/documents/:id/versions/:vid/restore` | Restore version |

### Comments

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/documents/:id/comments` | List comments |
| `POST` | `/documents/:id/comments` | Create comment |
| `POST` | `/documents/:id/comments/:cid/reply` | Reply to comment |
| `POST` | `/documents/:id/comments/:cid/resolve` | Resolve comment |

## Idempotency

For POST requests, include an `Idempotency-Key` header to ensure at-most-once execution:

```bash
curl -X POST https://api.gotipe.com/v1/documents \
  -H "Authorization: Bearer gt_live_sk_..." \
  -H "Idempotency-Key: req_abc123" \
  -H "Content-Type: application/json" \
  -d '{"title": "My Document"}'
```

Keys are stored in Valkey with a 24-hour TTL.
