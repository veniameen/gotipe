# Migrate from Tiptap

GoTipe and Tiptap share a similar extension-based philosophy, but GoTipe uses a block-first model with a Rust/WASM core instead of ProseMirror.

## Key Differences

| Concept | Tiptap | GoTipe |
|---------|--------|--------|
| Document model | ProseMirror node tree | Block array (flat + nested children) |
| State ownership | JavaScript | Rust/WASM |
| State mutations | `editor.chain()...run()` | `dispatch(Transaction)` via WASM |
| Extensions | `Extension.create()` | `defineExtension()` |
| CRDT | Yjs | Custom CRDT engine |
| React integration | `useEditor` (custom store) | `useEditor` (`useSyncExternalStore`) |
| CSS approach | Scoped CSS / Tailwind | `--gt-*` tokens, `.gotipe-*` classes |

## Installation

```bash
# Remove Tiptap
npm uninstall @tiptap/core @tiptap/react @tiptap/starter-kit @tiptap/pm

# Install GoTipe
npm install @gotipe/core @gotipe/react @gotipe/wasm @gotipe/migration
```

## Automated Migration

The `@gotipe/migration` package converts Tiptap JSON documents and extensions:

```ts
import { migrateTiptapDocument, migrateTiptapExtension } from '@gotipe/migration';

// Convert a Tiptap JSON document to GoTipe format
const tiptapDoc = {
  type: 'doc',
  content: [
    {
      type: 'heading',
      attrs: { level: 1 },
      content: [{ type: 'text', text: 'Hello World' }],
    },
    {
      type: 'paragraph',
      content: [
        { type: 'text', text: 'This is ' },
        { type: 'text', marks: [{ type: 'bold' }], text: 'bold' },
        { type: 'text', text: ' text.' },
      ],
    },
  ],
};

const gotipeDoc = migrateTiptapDocument(tiptapDoc);
// Result:
// {
//   version: 1,
//   blocks: [
//     { id: '<uuid>', type: 'heading', attrs: { level: 1 },
//       content: [{ text: 'Hello World', marks: [] }], children: [] },
//     { id: '<uuid>', type: 'paragraph', attrs: {},
//       content: [
//         { text: 'This is ', marks: [] },
//         { text: 'bold', marks: ['bold'] },
//         { text: ' text.', marks: [] },
//       ], children: [] },
//   ],
// }
```

## Extension Migration

```ts
// Tiptap extension
import { Extension } from '@tiptap/core';

const MyTiptapExtension = Extension.create({
  name: 'highlight',
  addAttributes() {
    return { color: { default: 'yellow' } };
  },
  addCommands() {
    return {
      toggleHighlight: (attrs) => ({ commands }) => {
        return commands.toggleMark('highlight', attrs);
      },
    };
  },
  addKeyboardShortcuts() {
    return { 'Mod-Shift-h': () => this.editor.commands.toggleHighlight() };
  },
});

// GoTipe equivalent
import { defineExtension } from '@gotipe/core';

const Highlight = defineExtension({
  name: 'highlight',
  schema: {
    type: 'mark',
    attrs: {
      color: { default: 'yellow' },
    },
  },
  commands: () => ({
    toggleHighlight: (attrs) => ({ type: 'toggleMark', mark: 'highlight', attrs }),
  }),
  keybindings: {
    'Mod-Shift-h': 'toggleHighlight',
  },
});
```

## React Component Migration

```tsx
// Tiptap
import { useEditor, EditorContent } from '@tiptap/react';
import StarterKit from '@tiptap/starter-kit';

function TiptapEditor() {
  const editor = useEditor({
    extensions: [StarterKit],
    content: '<p>Hello</p>',
  });
  return <EditorContent editor={editor} />;
}

// GoTipe
import { useEditor, EditorContent } from '@gotipe/react';
import { DefaultPreset } from '@gotipe/core';

function GoTipeEditor() {
  const editor = useEditor({
    extensions: [DefaultPreset],
    content: {
      version: 1,
      blocks: [
        { id: '1', type: 'paragraph', attrs: {}, content: [{ text: 'Hello', marks: [] }], children: [] },
      ],
    },
  });
  return <EditorContent editor={editor} />;
}
```

## Collaboration Migration

```ts
// Tiptap + Yjs
import { Collaboration } from '@tiptap/extension-collaboration';
import { HocuspocusProvider } from '@hocuspocus/provider';

// GoTipe (custom CRDT, not Yjs)
import { Collaboration, GoTipeProvider } from '@gotipe/collaboration';

Collaboration.configure({
  provider: GoTipeProvider.create({
    serverUrl: 'wss://sync.gotipe.com',
    documentId: 'doc-abc123',
    token: jwtToken,
  }),
});
```

## Batch Document Migration

```ts
import { migrateTiptapDocument } from '@gotipe/migration';

async function migrateAllDocuments() {
  const tiptapDocs = await db.query('SELECT id, content FROM documents');

  for (const doc of tiptapDocs) {
    const gotipeContent = migrateTiptapDocument(JSON.parse(doc.content));
    await db.query('UPDATE documents SET content = $1 WHERE id = $2', [
      JSON.stringify(gotipeContent),
      doc.id,
    ]);
  }
}
```
