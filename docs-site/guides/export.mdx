# Export and Import

GoTipe supports exporting to HTML, Markdown, PDF, and DOCX. PDF and DOCX modules are lazy-loaded to keep the core bundle small.

## Installation

```bash
npm install @gotipe/export
```

## Export HTML

HTML export is included in the core WASM bundle (~255KB):

```ts
import { exportHtml } from '@gotipe/export';

const html = await exportHtml(editor, {
  sanitize: true,              // ammonia + DOMPurify
  includeStyles: true,         // inline CSS
  wrapInDocument: false,       // full HTML document wrapper
});

// html = '<p>Hello <strong>world</strong></p>...'
```

## Export Markdown

Markdown export is also included in the core bundle:

```ts
import { exportMarkdown } from '@gotipe/export';

const markdown = await exportMarkdown(editor, {
  flavor: 'gfm',              // 'gfm' | 'commonmark'
  frontmatter: {              // optional YAML frontmatter
    title: 'My Document',
    date: '2026-02-11',
  },
});

// markdown = '# Hello\n\nThis is **bold** text...'
```

## Export PDF

PDF export uses typst under the hood. The WASM module is lazy-loaded (~400KB additional):

```ts
import { exportPdf } from '@gotipe/export';

const pdfBlob = await exportPdf(editor, {
  pageSize: 'A4',             // 'A4' | 'Letter' | 'Legal' | { width, height }
  margins: {
    top: '2.5cm',
    bottom: '2.5cm',
    left: '2cm',
    right: '2cm',
  },
  fontFamily: 'Inter',
  fontSize: '11pt',
  headerText: 'My Document',
  footerText: 'Page {page} of {pages}',
  includeTableOfContents: true,
});

// Download
const url = URL.createObjectURL(pdfBlob);
const a = document.createElement('a');
a.href = url;
a.download = 'document.pdf';
a.click();
```

<Warning>
PDF export loads an additional ~400KB WASM module on first use. Do not import it eagerly -- always use dynamic `import()` or the `exportPdf` function which handles lazy loading.
</Warning>

## Export DOCX

DOCX export uses docx-rs. The WASM module is lazy-loaded (~60KB additional):

```ts
import { exportDocx } from '@gotipe/export';

const docxBlob = await exportDocx(editor, {
  title: 'My Document',
  author: 'Alice',
  description: 'Generated by GoTipe',
  styles: {
    heading1: { fontSize: 24, bold: true },
    heading2: { fontSize: 18, bold: true },
    paragraph: { fontSize: 11, lineSpacing: 1.5 },
  },
});
```

## Export Plain Text

```ts
import { exportPlainText } from '@gotipe/export';

const text = await exportPlainText(editor);
```

## Import from Notion

```ts
import { importFromNotion } from '@gotipe/export';

// From Notion export ZIP file
const file = document.querySelector('input[type="file"]').files[0];
const document = await importFromNotion(file, {
  preserveIds: false,           // generate new block IDs
  convertDatabases: true,       // convert database views to tables
});

editor.commands.setContent(document);
```

## Import from Google Docs

```ts
import { importFromGoogleDocs } from '@gotipe/export';

// From HTML export or clipboard paste
const html = await clipboard.read();
const document = await importFromGoogleDocs(html, {
  preserveStyles: true,
  convertComments: true,
});

editor.commands.setContent(document);
```

## Import from HTML/Markdown

```ts
import { importHtml, importMarkdown } from '@gotipe/export';

const docFromHtml = await importHtml('<h1>Hello</h1><p>World</p>');
const docFromMd = await importMarkdown('# Hello\n\nWorld');

editor.commands.setContent(docFromHtml);
```

## Feature Flags (WASM Bundle Size)

The Rust `gotipe-export` crate uses feature flags to control what gets compiled into WASM:

| Feature | Default | WASM Size Impact |
|---------|---------|-----------------|
| `html` | Yes | Included in core |
| `markdown` | Yes | Included in core |
| `plaintext` | Yes | Included in core |
| `pdf` | No | +400KB (lazy) |
| `docx` | No | +60KB (lazy) |
