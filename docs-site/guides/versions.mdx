# Versions

The `@gotipe/versions` extension provides version history with named snapshots, auto-save, diffing, and restore.

## Installation

```bash
npm install @gotipe/versions
```

## Basic Setup

```ts
import { Versions } from '@gotipe/versions';
import { createEditor, DefaultPreset } from '@gotipe/core';

const editor = createEditor({
  extensions: [
    DefaultPreset,
    Versions.configure({
      provider: 'cloud',
      cloudUrl: 'https://api.gotipe.com/v1',
      token: jwtToken,
      autoSave: {
        enabled: true,
        intervalMs: 30_000,     // auto-save every 30s
        minChanges: 5,          // only if at least 5 changes
      },
    }),
  ],
});
```

## Creating Versions

```ts
// Create a named version (manual snapshot)
const version = await editor.versions.create({
  name: 'Before refactor',
  description: 'Saving state before major restructuring',
});
// => { id: 'ver_abc123', name: 'Before refactor', createdAt: '...', createdBy: { id, name } }
```

## Listing Versions

```ts
const versions = await editor.versions.list({
  limit: 20,
  offset: 0,
  includeAutoSaves: false,    // exclude auto-save versions
});

// Each version:
// {
//   id: 'ver_abc123',
//   name: 'Before refactor',
//   description: '...',
//   createdAt: '2026-02-10T12:00:00Z',
//   createdBy: { id: 'user-1', name: 'Alice' },
//   isAutoSave: false,
//   blockCount: 42,
//   wordCount: 1250,
// }
```

## Restoring Versions

```ts
// Restore a previous version (creates a new version as backup first)
await editor.versions.restore('ver_abc123');

// Restore without creating backup
await editor.versions.restore('ver_abc123', { createBackup: false });
```

## Comparing Versions

```ts
const diff = await editor.versions.compare('ver_abc123', 'ver_def456');

// diff = {
//   added: [{ blockId, type, content }],
//   removed: [{ blockId, type, content }],
//   modified: [{ blockId, before, after }],
//   stats: { added: 3, removed: 1, modified: 5 },
// }
```

## Version Viewer (React)

```tsx
import { VersionViewer, VersionDiff } from '@gotipe/versions/react';

function VersionPanel({ editor }) {
  const [selectedVersion, setSelectedVersion] = useState(null);
  const [compareWith, setCompareWith] = useState(null);

  if (compareWith) {
    return (
      <VersionDiff
        editor={editor}
        versionA={selectedVersion}
        versionB={compareWith}
        onRestore={(versionId) => editor.versions.restore(versionId)}
      />
    );
  }

  return (
    <VersionViewer
      editor={editor}
      version={selectedVersion}
      onRestore={() => editor.versions.restore(selectedVersion.id)}
      onCompare={(v) => setCompareWith(v)}
    />
  );
}
```

## Auto-Save Configuration

```ts
Versions.configure({
  autoSave: {
    enabled: true,
    intervalMs: 30_000,
    minChanges: 5,
    maxVersions: 100,          // prune oldest auto-saves beyond this
    onAutoSave: (version) => {
      console.log('Auto-saved:', version.id);
    },
  },
});
```

## Local Storage Provider

For offline or non-cloud usage:

```ts
Versions.configure({
  provider: 'local',
  storage: 'indexeddb',         // 'indexeddb' | 'memory'
  maxVersions: 50,
});
```

## Configuration Options

```ts
Versions.configure({
  provider: 'cloud' | 'local',
  cloudUrl: string,
  token: string,
  autoSave: {
    enabled: boolean,
    intervalMs: number,
    minChanges: number,
    maxVersions: number,
  },
  storage: 'indexeddb' | 'memory',
  maxVersions: number,
  onVersionCreated: (version) => void,
  onVersionRestored: (version) => void,
});
```
