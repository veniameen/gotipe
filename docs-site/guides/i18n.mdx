# Internationalization (i18n)

The `@gotipe/i18n` extension provides UI translations, RTL/BiDi support, and custom locale definitions.

## Installation

```bash
npm install @gotipe/i18n
```

## Basic Setup

```ts
import { I18n } from '@gotipe/i18n';
import { createEditor, DefaultPreset } from '@gotipe/core';

const editor = createEditor({
  extensions: [
    DefaultPreset,
    I18n.configure({
      locale: 'fr',              // default locale
      fallbackLocale: 'en',
    }),
  ],
});
```

## Changing Locale at Runtime

```ts
editor.commands.setLocale('de');

// Get current locale
const locale = editor.i18n.getLocale();   // 'de'
```

## Built-In Locales

GoTipe ships with these locales:

| Code | Language | RTL |
|------|----------|-----|
| `en` | English | No |
| `es` | Spanish | No |
| `fr` | French | No |
| `de` | German | No |
| `pt` | Portuguese | No |

| `ja` | Japanese | No |
| `ko` | Korean | No |
| `ar` | Arabic | Yes |
| `he` | Hebrew | Yes |
| `fa` | Persian | Yes |

## Translation Helper

Use the `t()` function in extensions and components:

```ts
import { t } from '@gotipe/i18n';

// In an extension
const MyExtension = defineExtension({
  name: 'myBlock',
  slashCommands: [
    {
      name: t('my_block.name'),            // localized name
      description: t('my_block.description'),
    },
  ],
});
```

```tsx
// In React components
import { useTranslation } from '@gotipe/i18n/react';

function Toolbar({ editor }) {
  const { t } = useTranslation(editor);

  return (
    <div>
      <button title={t('toolbar.bold')}><BoldIcon /></button>
      <button title={t('toolbar.italic')}><ItalicIcon /></button>
    </div>
  );
}
```

## Custom Locale

Define your own translations:

```ts
import { defineLocale } from '@gotipe/i18n';

const customLocale = defineLocale({
  code: 'uk',
  name: 'Ukrainian',
  dir: 'ltr',
  translations: {
    'toolbar.bold': 'Жирний',
    'toolbar.italic': 'Курсив',
    'toolbar.link': 'Посилання',
    'slash.paragraph': 'Параграф',
    'slash.heading': 'Заголовок',
    'slash.bulletList': 'Маркований список',
    'slash.numberedList': 'Нумерований список',
    'slash.codeBlock': 'Блок коду',
    'slash.image': 'Зображення',
    'placeholder.empty': 'Натисніть "/" для команд...',
    'placeholder.heading': 'Заголовок',
    'ai.ghostText.accept': 'Tab для прийняття',
    'ai.ghostText.dismiss': 'Esc для відхилення',
    'comments.add': 'Додати коментар',
    'comments.resolve': 'Вирішити',
    'comments.reply': 'Відповісти',
  },
});

I18n.configure({
  locale: 'uk',
  customLocales: [customLocale],
});
```

## Extending Built-In Locales

Override specific keys in an existing locale:

```ts
I18n.configure({
  locale: 'en',
  overrides: {
    en: {
      'placeholder.empty': 'Start writing or press "/" for commands...',
      'slash.paragraph': 'Text',
    },
  },
});
```

## RTL and BiDi Support

RTL locales are automatically detected. The editor adds `dir="rtl"` to the root element:

```ts
I18n.configure({
  locale: 'ar',    // automatically enables RTL
});
```

Manual override:

```ts
I18n.configure({
  locale: 'en',
  dir: 'rtl',      // force RTL even for LTR locale
});
```

Mixed-direction content is supported per-block:

```ts
editor.commands.setBlockDir('block-abc', 'rtl');
```

CSS tokens for RTL:

```css
.gotipe-editor[dir='rtl'] {
  --gt-block-indent-side: right;
  --gt-text-align-default: right;
}
```
