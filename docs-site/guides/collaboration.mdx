# Collaboration

GoTipe includes a custom CRDT engine with a binary sync protocol. It does not use Yjs -- the CRDT is built specifically for block-first documents.

## Installation

```bash
npm install @gotipe/collaboration
```

## GoTipeProvider (WebSocket)

The primary provider for real-time collaboration via GoTipe Cloud or a self-hosted server:

```ts
import { Collaboration, GoTipeProvider } from '@gotipe/collaboration';

const editor = createEditor({
  extensions: [
    DefaultPreset,
    Collaboration.configure({
      provider: GoTipeProvider.create({
        serverUrl: 'wss://sync.gotipe.com',
        documentId: 'doc-abc123',
        token: jwtToken,
      }),
    }),
  ],
});
```

## Binary Sync Protocol

All sync messages use a binary protocol with zstd compression. Message types:

| Byte | Type | Description |
|------|------|-------------|
| `0x01` | SyncStep1 | Initial state vector |
| `0x02` | SyncStep2 | Missing updates |
| `0x03` | Update | Incremental update |
| `0x04` | Awareness | Cursor/presence data |
| `0x05` | AwarenessQuery | Request awareness |
| `0x06` | Auth | Authentication |
| `0x07` | AuthResult | Auth response |
| `0x08` | Error | Error message |
| `0x09` | Ping/Pong | Keep-alive |

## Reconnection and Offline Queue

The provider handles network interruptions automatically:

```ts
GoTipeProvider.create({
  serverUrl: 'wss://sync.gotipe.com',
  documentId: 'doc-abc123',
  token: jwtToken,
  reconnect: {
    maxRetries: 10,
    baseDelay: 1000,       // ms
    maxDelay: 30000,       // ms
    backoffFactor: 2,
  },
  offlineQueue: true,       // queue changes while offline
});
```

## WebRTC Provider

Peer-to-peer sync for local networks or when server latency matters:

```ts
import { WebRTCProvider } from '@gotipe/collaboration';

Collaboration.configure({
  provider: WebRTCProvider.create({
    signalingServer: 'wss://signal.gotipe.com',
    roomId: 'doc-abc123',
    password: 'optional-room-password',
  }),
});
```

## BroadcastProvider

Sync across browser tabs using the BroadcastChannel API:

```ts
import { BroadcastProvider } from '@gotipe/collaboration';

Collaboration.configure({
  provider: BroadcastProvider.create({
    channelName: 'doc-abc123',
  }),
});
```

## IndexedDB Provider

Persist document state locally for offline support:

```ts
import { IndexedDBProvider } from '@gotipe/collaboration';

Collaboration.configure({
  providers: [
    GoTipeProvider.create({ serverUrl, documentId, token }),
    IndexedDBProvider.create({ dbName: 'gotipe-docs', documentId }),
  ],
});
```

## Awareness (Cursors and Presence)

Show collaborator cursors, selections, and presence:

```ts
import { Collaboration, AwarenessCursors } from '@gotipe/collaboration';

Collaboration.configure({
  provider: GoTipeProvider.create({ serverUrl, documentId, token }),
  awareness: {
    user: {
      name: 'Alice',
      color: '#e91e63',
      avatar: 'https://example.com/alice.jpg',
    },
  },
});

// Add cursor rendering extension
const editor = createEditor({
  extensions: [
    DefaultPreset,
    Collaboration.configure({ /* ... */ }),
    AwarenessCursors.configure({
      cursorStyle: 'line',    // 'line' | 'block'
      selectionOpacity: 0.2,
    }),
  ],
});
```

### Access Awareness State

```ts
// Get connected users
const users = editor.collaboration.getUsers();
// [{ clientId: 1, name: 'Alice', color: '#e91e63', cursor: { blockId, offset } }]

// Listen for changes
editor.collaboration.onUsersChange((users) => {
  updatePresenceUI(users);
});
```

## Multiple Providers

Combine providers for resilience:

```ts
Collaboration.configure({
  providers: [
    GoTipeProvider.create({ serverUrl, documentId, token }),
    BroadcastProvider.create({ channelName: documentId }),
    IndexedDBProvider.create({ dbName: 'gotipe-docs', documentId }),
  ],
});
```
