# Атлас GoTipe

Рисунок вида библиотеки. Вид сначала рисуется здесь и принимается владельцем,
потом переносится в `packages/theme` и `packages/block-editor`.

- `src/tokens.css`, `src/tokens-views.css`, `src/tokens-ui.css` — токены. Это
  единственные файлы с литеральными цветами и размерами:
  - `--gt-*` принадлежат библиотеке: темы light/dark, пресеты видов через
    `data-gt-view`, размеры интерфейса;
  - `--at-*` оформляют саму страницу атласа.
- `src/document.css`, `src/blocks.css` — документ и блоки, общие для всех видов.
- `src/views/*.css` — компоновка видов: notion, docs, modern, minimal.
- `src/ui/*.css` — всплывающие элементы, меню, панели, совместная работа, ревью,
  состояния; элементы строки (упоминания, эмодзи, формулы), поиск и счётчик, вёрстка
  текста и ячеек, история версий.
- `src/content/` — настоящий текст и его рисунки.
- `src/figures/NN-*.html` — кадры по номерам; `src/shell.html` — страница;
  `src/atlas.js` — переключатель темы вверху страницы: светлая или тёмная.
- `atlas.html` — собранный файл. Открывается в браузере без сервера и сети.

Кадр пишется один раз между `<!-- @frame frame=… view=… w=… -->` и `<!-- @end -->`.
Тему всех кадров сразу выбирает переключатель вверху страницы, как в Specimen v6; узкие кадры стоят рядом, широкие — по одному.

Параметры кадра:
- `w` — ширина: 320, 375, 480, 768, 1024 или 1440;
- `h` — экран с обрезкой снизу;
- `min` — наименьшая высота кадра с меню;
- `label` — подпись к кадру.

Оглавление и заголовки разделов собираются из `data-section` и заголовков кадров.

## Сборка и проверка

```bash
node design/atlas/build.mjs
node design/atlas/check.mjs
```

Без браузера проверка падает, если:
- `atlas.html` не совпадает со сборкой из частей;
- вне файлов токенов встречается литеральный цвет, размер, вес, межстрочный
  интервал, семейство шрифта или размер в условии `@media` / `@container`;
- какой-то `var()` не определён;
- в разметке есть `style=`, внешний ресурс или цвет, заданный атрибутом.

В Chromium проверка проходит страницу дважды, переключая тему тем же переключателем,
и падает, если:
- на странице есть ошибки или сетевые запросы;
- переключатель не сменил тему, фон кадра не соответствует теме, у фигуры нет кадров,
  а у пункта оглавления — фигуры;
- что-то выходит за кадр по горизонтали или по вертикали (кроме обрезанных экранов
  и содержимого прокручиваемых областей) либо обрезается;
- соседние блоки наложились или ручка блока закрывает текст;
- контраст текста ниже порога на его настоящем фоне, с учётом всплывающих
  поверхностей и заливок.

Снимки кадров в обеих темах сохраняются в `output/atlas/` (вне Git); флаг
`--no-shots` их пропускает. Без браузеров Playwright проверку можно запустить в
установленном Chrome: `GOTIPE_E2E_CHANNEL=chrome node design/atlas/check.mjs`.

## Кадры

1–4. Один документ в четырёх видах: notion, docs, modern, minimal.

5. Ширины 375, 320, 768 и 1440.

6–11. Взаимодействие:
- выделение, ссылка и цвет;
- меню «/»;
- ручка, меню блока и перетаскивание;
- таблица: полосы, что добавляют строку и столбец, широкая таблица, меню столбца и строки;
- изображение;
- пустые блоки и пустая страница.

12–16. Совместная работа и ревью:
- курсоры;
- комментарии;
- предложения правок;
- версии;
- строка команды модели и её подсказка.

17. Состояния:
- загрузка;
- ошибки;
- только чтение;
- Markdown как есть;
- недоступно;
- фокус с клавиатуры.

18. Блоки:
- задачи: флажок под указателем, пустая задача;
- раскрывающиеся блоки: закрытый, пустой, фокус на шевроне;
- файл и его действия под указателем;
- вставка: карточка страницы и пустая, которая просит ссылку;
- формула как TeX.

19. PageEditor: страница вики на общих компонентах; по умолчанию notion, docs — через `view`.

20–21. Сайт — по концепции владельца (base44), с синим акцентом библиотеки вместо фиолетового.
Текст, линии и акцент — `--gt-*`; голос сайта — `--site-*` в `src/tokens-site.css`: Inter
(заголовки 500 с плотным трекингом и текст) и JetBrains Mono (метки, бейджи, код) первыми, системные
семейства библиотеки — запасными, файлы шрифтов не подключаются; тонированные сцены, карточки,
светлые и тёмные значения. Вёрстка — `src/site/`: `landing.css` (оболочка, шапка, первый экран,
факты), `landing-window.css` (окна с документом), `landing-sections.css` (возможности, виды),
`landing-closing.css` (тёмная панель, запуск, лицензии, финал, подвал), `docs.css`:
- главная: плавающая шапка-пилюля; первый экран на голубой сцене с диагональными бликами — три
  строки «Your editor. Your engine. Your rules.», метка «v0.1», две кнопки, строка установки,
  карточка «The GoTipe stack» и полоса «Not a wrapper. A foundation.»; окно «Plain text. Rich
  possibilities.» — 12 строк Markdown с номерами слева и тот же документ справа (разметка
  библиотеки, панель форматирования, курсор соавтора); проверяемые факты; бенто из трёх
  тонированных карточек (голубая, шалфей, песок) и сетка 3×3 с бейджами MIT и Commercial; «One
  markup. Four looks.» — список видов рядом с документом вида; тёмная панель «From install to your
  first edit.» — шаги и настоящий пример React (внутри — тёмная тема библиотеки через
  `data-theme="dark"`); три способа запуска с крупными числами; две карточки лицензий; финальная
  сцена; подвал;
- документация: спокойная шапка с версией и полем поиска ⌘K; слева разделы с моно-заголовками,
  текущая страница — голубой плашкой; в середине страница в виде docs — это документ GoTipe; справа
  оглавление; поиск в диалоге; на ноутбуке уходит оглавление, на планшете и телефоне разделы — за
  кнопку меню.

22–30. Новые возможности:
- упоминания: в тексте и под указателем, список после «@» с ↵ у выбранного, никого не
  найдено;
- эмодзи: список после «:», выбор из меню «/» — поиск, разделы, недавние, имя в
  подсказке; свой эмодзи в строке;
- формула в строке: набрана шрифтом документа, поле TeX с рисунком, TeX с ошибкой;
- поиск и замена: строка в правом верхнем углу, совпадения и текущее, замена, ничего не
  найдено, телефон;
- счётчик слов и символов: без лимита, у лимита, за лимитом;
- выравнивание в «Ещё», выровненные заголовок и абзацы, шрифт и размер в панели modern;
- невидимые символы; абзац справа налево с ручкой в правом поле;
- таблица: заголовок на два столбца и ячейка на две строки, выделение ячеек,
  «Объединить ячейки» и «Разделить ячейку» в меню строки и столбца;
- история версий: сравнение с текущей по блокам, восстановление с отменой, телефон.
