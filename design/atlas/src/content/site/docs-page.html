Usage

Tables are part of the default preset. Insert one with a command:

editor.ts 
1
2
3
4
5import { createEditor } from "@gotipe/core";
import { DefaultPreset } from "@gotipe/core/presets";

const editor = await createEditor({ extensions: [DefaultPreset] });
editor.chain().insertTable({ rows: 3, cols: 3, withHeader: true }).run();

Commands

CommandDescription
insertTableInserts a table after the current block.
goToNextCellMoves to the next cell; Tab.
goToPrevCellMoves to the previous cell; Shift+Tab.

Merged cells are kept, but a table with merged cells takes no row or column edits.
