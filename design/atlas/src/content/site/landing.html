The editor you own, down to the engine.

GoTipe is a document editor framework with its own engine in TypeScript and Rust/WASM: lossless Markdown, a ready block editor, review and real-time collaboration — and no third-party editor underneath.

What's inside

Everything a document needs. Most of it MIT.

The engine and every service around it are open source. Only the ready-made interface has a commercial license.

Own engine

Transactions, history, selection and IME in TypeScript, with the same contract in Rust/WASM.

Lossless Markdown

Our own parser: an edit rewrites only the block it touched, the rest of the file stays as written.

Slash menu, drag handle, bubble toolbar, tables, media and code — ready for React.

Page editor

MIT

14import { BlockEditor } from "@gotipe/block-editor";
import { FullPreset } from "@gotipe/core/presets";
import { useEditor } from "@gotipe/react";
import "@gotipe/theme/theme.css";
import "@gotipe/theme/base.css";

export function Notes({ content, save }) {
  const editor = useEditor({
    extensions: [FullPreset],
    content,
    onUpdate: ({ editor }) => save(editor.getJSON()),
  });
  return <BlockEditor editor={editor} />;
}

Run it your way

In the browser, in WebAssembly, on your servers.

JavaScript engine

MIT

The default. The whole editing model in TypeScript, nothing extra to load.

  • About 96 KB gzip with Markdown
  • Server rendering to HTML, Markdown and text

Rust/WASM engine

MIT

The same API and document contract, compiled from Rust. Required for real-time collaboration.

  • About 590 KB gzip
  • CRDT, cursors and reconnect

GoTipe Cloud

MIT

A Go service you run: documents, permissions, sync, exports and an AI proxy.

  • PostgreSQL and Valkey
  • One Docker Compose file
