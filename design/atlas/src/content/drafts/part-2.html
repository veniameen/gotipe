What changes

  • Every transaction first goes into the log and only then to the server.
  • When the connection is back, the log goes out as a batch and the server answers with a new version of the document.
  • A conflict is resolved per block:
    • someone else’s edit to a block doesn’t overwrite yours;
    • both versions stay, yours as a suggestion.

editor.on("transaction", async ({ steps, version }: Transaction) => {
  await drafts.append(documentId, { steps, version });
  if (navigator.onLine) await drafts.flush(documentId, { retries: 3 });
});

Rollout order

  1. Turn the log on for 5% of web users.
  2. Compare the share of lost edits with the control group for a week.
  3. Open to everyone, starting with the macOS app.

Before release 2.9 a draft doesn’t move between devices: an edit from a laptop won’t appear on the phone until it is sent.
