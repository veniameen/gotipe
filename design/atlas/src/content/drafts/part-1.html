An edit made offline is currently lost if the tab is closed before the connection returns. In release 2.8 the editor writes every transaction to a local log and sends it as soon as the network is back. The decision rests on ADR-0031 and on the October support requests, which were reviewed by IOIlya Orlov.

A draft is stored only on the device and is encrypted with the session key. On sign-out it is deleted along with the key.

How it works

The log lives in IndexedDB and survives an app restart. The server accepts a batch of transactions whole or rejects it: half a batch can’t be written.
