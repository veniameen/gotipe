## Архитектура AI Layer

AI в GoTipe — часть Rust/WASM core (`gotipe-ai` crate), а не внешний плагин. Provider-agnostic: один и тот же API работает с OpenAI, Anthropic, Gemini, Ollama, любым custom провайдером. Подробности общей архитектуры в [01-architecture.md](01-architecture.md).

**Три уровня AI:**

| Уровень | Название | Описание | Взаимодействие |
|---------|----------|----------|----------------|
| **Level 1** | Inline AI (Ghost Text) | Автокомплит при наборе текста | Debounce 500ms → ghost text → Tab/Escape |
| **Level 2** | Context AI | AI-команды на выделенном тексте/документе | Bubble menu "Improve", Slash menu "Continue Writing" / "Ask AI" |
| **Level 3** | Agent AI Toolkit | AI как агент — комментирует, правит, генерирует | AI Command Bar, AI Comments, AI Proofread, AI Add Paragraph |

Все три уровня используют общий Provider Interface и ContextBuilder. Каждый уровень подключается независимо.

**Ключевые принципы:**

| Принцип | Реализация |
|---------|------------|
| Provider-agnostic | Единый `AiProvider` trait/interface, реализации подключаются как конфиг |
| Context in Rust | `ContextBuilder` работает в WASM — LLM context собирается максимально быстро |
| Streaming-first | Все providers возвращают `AsyncIterator<string>`, ghost text обновляется по мере генерации |
| Privacy by design | Self-hosted (Ollama) — данные не покидают машину пользователя |
| AI = Extension | AI подключается через `AIInline.configure()`, см. [05-extensions.md](05-extensions.md) |
| 3 levels independent | Каждый уровень AI подключается отдельным extension, можно использовать любую комбинацию |

## Provider Interface

### Rust Trait

```rust
// crates/gotipe-ai/src/provider.rs
use async_trait::async_trait;
use serde::{Serialize, Deserialize};
use std::pin::Pin;
use futures::Stream;

/// Сообщение для LLM
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct AiMessage {
    pub role: AiRole,
    pub content: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum AiRole {
    System,
    User,
    Assistant,
}

/// Параметры генерации
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct AiGenerateParams {
    pub messages: Vec<AiMessage>,
    pub max_tokens: Option<u32>,
    pub temperature: Option<f32>,
    pub stop_sequences: Vec<String>,
    /// Подсказка: для inline completion используем low temperature
    pub mode: AiMode,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum AiMode {
    /// Ghost text / autocomplete — быстрые, короткие ответы
    InlineCompletion,
    /// AI commands — rewrite, expand, summarize
    Command,
    /// Свободная генерация
    FreeGeneration,
}

/// Результат генерации (один chunk)
#[derive(Debug, Clone)]
pub struct AiChunk {
    pub delta: String,
    pub finish_reason: Option<FinishReason>,
}

#[derive(Debug, Clone)]
pub enum FinishReason {
    Stop,
    MaxTokens,
    Error(String),
}

/// Provider — абстракция над LLM API
#[async_trait]
pub trait AiProvider: Send + Sync {
    /// Имя провайдера (для логирования, выбора)
    fn name(&self) -> &str;

    /// Поддерживает ли streaming
    fn supports_streaming(&self) -> bool { true }

    /// Streaming генерация — возвращает Stream из chunks
    async fn generate_stream(
        &self,
        params: AiGenerateParams,
    ) -> Result<Pin<Box<dyn Stream<Item = Result<AiChunk, AiError>> + Send>>, AiError>;

    /// Non-streaming генерация (fallback)
    async fn generate(
        &self,
        params: AiGenerateParams,
    ) -> Result<String, AiError> {
        use futures::StreamExt;
        let mut stream = self.generate_stream(params).await?;
        let mut result = String::new();
        while let Some(chunk) = stream.next().await {
            result.push_str(&chunk?.delta);
        }
        Ok(result)
    }

    /// Проверка доступности провайдера
    async fn health_check(&self) -> Result<(), AiError>;
}

#[derive(Debug, thiserror::Error)]
pub enum AiError {
    #[error("Provider unavailable: {0}")]
    Unavailable(String),
    #[error("Rate limited, retry after {retry_after_ms}ms")]
    RateLimited { retry_after_ms: u64 },
    #[error("Context too long: {tokens} tokens, max {max_tokens}")]
    ContextTooLong { tokens: usize, max_tokens: usize },
    #[error("Auth error: {0}")]
    AuthError(String),
    #[error("Generation error: {0}")]
    GenerationError(String),
}
```

## Реализации провайдеров

### OpenAI Provider

```typescript
// packages/ai/src/providers/openai.ts
import type { AiProvider, AiGenerateParams, AiChunk } from '../types/provider';

export interface OpenAIProviderOptions {
  apiKey: string;
  model?: string;
  baseUrl?: string;
  organization?: string;
}

export class OpenAIProvider implements AiProvider {
  name = 'openai';
  supportsStreaming = true;

  private apiKey: string;
  private model: string;
  private baseUrl: string;

  constructor(options: OpenAIProviderOptions) {
    this.apiKey = options.apiKey;
    this.model = options.model ?? 'gpt-4o-mini';
    this.baseUrl = options.baseUrl ?? 'https://api.openai.com/v1';
  }

  async *generateStream(params: AiGenerateParams): AsyncIterable<AiChunk> {
    const response = await fetch(`${this.baseUrl}/chat/completions`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${this.apiKey}`,
      },
      body: JSON.stringify({
        model: this.model,
        messages: params.messages.map(m => ({
          role: m.role,
          content: m.content,
        })),
        max_tokens: params.maxTokens ?? this.defaultMaxTokens(params.mode),
        temperature: params.temperature ?? this.defaultTemperature(params.mode),
        stop: params.stopSequences.length > 0 ? params.stopSequences : undefined,
        stream: true,
      }),
    });

    if (!response.ok) {
      const error = await response.json();
      if (response.status === 429) {
        throw { code: 'rate_limited', retryAfterMs: 1000 };
      }
      throw { code: 'generation_error', message: error.error?.message };
    }

    const reader = response.body!.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      buffer += decoder.decode(value, { stream: true });
      const lines = buffer.split('\n');
      buffer = lines.pop()!;

      for (const line of lines) {
        if (!line.startsWith('data: ')) continue;
        const data = line.slice(6);
        if (data === '[DONE]') return;

        const parsed = JSON.parse(data);
        const delta = parsed.choices?.[0]?.delta?.content ?? '';
        const finishReason = parsed.choices?.[0]?.finish_reason;

        if (delta || finishReason) {
          yield {
            delta,
            finishReason: finishReason === 'stop' ? 'stop'
              : finishReason === 'length' ? 'max_tokens'
              : undefined,
          };
        }
      }
    }
  }

  async generate(params: AiGenerateParams): Promise<string> {
    let result = '';
    for await (const chunk of this.generateStream(params)) {
      result += chunk.delta;
    }
    return result;
  }

  async healthCheck(): Promise<void> {
    const response = await fetch(`${this.baseUrl}/models`, {
      headers: { 'Authorization': `Bearer ${this.apiKey}` },
    });
    if (!response.ok) throw new Error(`OpenAI health check failed: ${response.status}`);
  }

  private defaultTemperature(mode: string): number {
    switch (mode) {
      case 'inline_completion': return 0.1;
      case 'command': return 0.3;
      default: return 0.7;
    }
  }

  private defaultMaxTokens(mode: string): number {
    switch (mode) {
      case 'inline_completion': return 128;
      case 'command': return 1024;
      default: return 2048;
    }
  }
}
```

### Ollama Provider (self-hosted)

```typescript
// packages/ai/src/providers/ollama.ts
import type { AiProvider, AiGenerateParams, AiChunk } from '../types/provider';

export interface OllamaProviderOptions {
  /** Ollama server URL, default http://localhost:11434 */
  baseUrl?: string;
  /** Model name, e.g. 'llama3.1', 'mistral', 'codellama' */
  model?: string;
}

export class OllamaProvider implements AiProvider {
  name = 'ollama';
  supportsStreaming = true;

  private baseUrl: string;
  private model: string;

  constructor(options: OllamaProviderOptions = {}) {
    this.baseUrl = options.baseUrl ?? 'http://localhost:11434';
    this.model = options.model ?? 'llama3.1';
  }

  async *generateStream(params: AiGenerateParams): AsyncIterable<AiChunk> {
    // Ollama /api/chat endpoint — совместим с OpenAI message format
    const response = await fetch(`${this.baseUrl}/api/chat`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        model: this.model,
        messages: params.messages.map(m => ({
          role: m.role,
          content: m.content,
        })),
        stream: true,
        options: {
          temperature: params.temperature ?? 0.3,
          num_predict: params.maxTokens ?? 512,
          stop: params.stopSequences,
        },
      }),
    });

    if (!response.ok) {
      throw { code: 'generation_error', message: `Ollama error: ${response.status}` };
    }

    const reader = response.body!.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      buffer += decoder.decode(value, { stream: true });
      const lines = buffer.split('\n');
      buffer = lines.pop()!;

      for (const line of lines) {
        if (!line.trim()) continue;
        const parsed = JSON.parse(line);

        yield {
          delta: parsed.message?.content ?? '',
          finishReason: parsed.done ? 'stop' : undefined,
        };
      }
    }
  }

  async generate(params: AiGenerateParams): Promise<string> {
    let result = '';
    for await (const chunk of this.generateStream(params)) {
      result += chunk.delta;
    }
    return result;
  }

  async healthCheck(): Promise<void> {
    const response = await fetch(`${this.baseUrl}/api/tags`);
    if (!response.ok) throw new Error(`Ollama not reachable at ${this.baseUrl}`);

    const data = await response.json();
    const available = data.models?.map((m: any) => m.name) ?? [];
    if (!available.some((n: string) => n.startsWith(this.model))) {
      throw new Error(
        `Model "${this.model}" not found. Available: ${available.join(', ')}. ` +
        `Run: ollama pull ${this.model}`
      );
    }
  }
}
```

### Anthropic Provider

```typescript
// packages/ai/src/providers/anthropic.ts
import type { AiProvider, AiGenerateParams, AiChunk } from '../types/provider';

export interface AnthropicProviderOptions {
  apiKey: string;
  model?: string;
}

export class AnthropicProvider implements AiProvider {
  name = 'anthropic';
  supportsStreaming = true;

  private apiKey: string;
  private model: string;

  constructor(options: AnthropicProviderOptions) {
    this.apiKey = options.apiKey;
    this.model = options.model ?? 'claude-sonnet-4-20250514';
  }

  async *generateStream(params: AiGenerateParams): AsyncIterable<AiChunk> {
    const systemMessage = params.messages.find(m => m.role === 'system');
    const nonSystemMessages = params.messages.filter(m => m.role !== 'system');

    const response = await fetch('https://api.anthropic.com/v1/messages', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'x-api-key': this.apiKey,
        'anthropic-version': '2023-06-01',
      },
      body: JSON.stringify({
        model: this.model,
        max_tokens: params.maxTokens ?? 1024,
        system: systemMessage?.content,
        messages: nonSystemMessages.map(m => ({
          role: m.role,
          content: m.content,
        })),
        stream: true,
      }),
    });

    if (!response.ok) {
      const error = await response.json();
      throw { code: 'generation_error', message: error.error?.message };
    }

    const reader = response.body!.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      buffer += decoder.decode(value, { stream: true });
      const lines = buffer.split('\n');
      buffer = lines.pop()!;

      for (const line of lines) {
        if (!line.startsWith('data: ')) continue;
        const parsed = JSON.parse(line.slice(6));

        if (parsed.type === 'content_block_delta') {
          yield { delta: parsed.delta?.text ?? '' };
        }
        if (parsed.type === 'message_stop') {
          yield { delta: '', finishReason: 'stop' };
        }
      }
    }
  }

  async generate(params: AiGenerateParams): Promise<string> {
    let result = '';
    for await (const chunk of this.generateStream(params)) {
      result += chunk.delta;
    }
    return result;
  }

  async healthCheck(): Promise<void> {
    // Anthropic не имеет /models endpoint — делаем minimal completion
    await this.generate({
      messages: [{ role: 'user', content: 'ping' }],
      maxTokens: 1,
      mode: 'inline_completion',
    });
  }
}
```

## Ghost Text (Inline Suggestions)

Ghost text — полупрозрачный текст, показывающий LLM-предсказание прямо в позиции курсора. Пользователь принимает его клавишей `Tab` или отклоняет через `Escape`.

### Rendering Flow

```
User stops typing (debounce 500ms)
        │
        ▼
┌─────────────────────────┐
│ 1. Trigger Check        │  Проверяем: курсор в конце строки?
│    shouldTrigger()      │  Не в code block? Нет active selection?
└────────┬────────────────┘
         │ yes
         ▼
┌─────────────────────────┐
│ 2. Build Context        │  ContextBuilder (Rust/WASM) собирает
│    contextBuilder       │  prompt из документа
│    .build(state)        │  (текущий блок + соседние + заголовок)
└────────┬────────────────┘
         │ AiGenerateParams
         ▼
┌─────────────────────────┐
│ 3. Stream Request       │  Provider.generateStream(params)
│    provider             │  SSE/NDJSON → AsyncIterable<AiChunk>
│    .generateStream()    │
└────────┬────────────────┘
         │ chunks (streaming)
         ▼
┌─────────────────────────┐
│ 4. Update Ghost State   │  SuggestionState accumulates chunks:
│    suggestionState      │  "Thi" → "This i" → "This is a"
│    .appendChunk(delta)  │  Каждый chunk → новый Decoration
└────────┬────────────────┘
         │ Decoration[]
         ▼
┌─────────────────────────┐
│ 5. Render Decoration    │  Framework adapter рендерит
│    <GhostText />        │  <span class="gotipe-ghost-text">
│                         │  с opacity: 0.4, pointer-events: none
└────────┬────────────────┘
         │
         ├── Tab pressed ──────► 6a. Accept: insert ghost text
         │                            as real content (Transaction)
         │
         ├── Escape pressed ───► 6b. Reject: clear SuggestionState,
         │                            remove decoration
         │
         └── User types ──────► 6c. Dismiss: clear on any input,
                                      re-trigger after new debounce
```

### SuggestionState (Rust)

```rust
// crates/gotipe-ai/src/suggestion.rs
use crate::provider::AiChunk;
use gotipe_core::{BlockId, Decoration, DecorationType};

/// Состояние ghost text suggestion
#[derive(Debug, Clone)]
pub struct SuggestionState {
    /// Блок, в котором показывается ghost text
    block_id: BlockId,
    /// Позиция курсора (offset внутри блока)
    cursor_offset: usize,
    /// Накопленный текст ghost suggestion
    accumulated_text: String,
    /// Генерация завершена?
    is_complete: bool,
    /// ID текущего запроса (для отмены outdated)
    request_id: u64,
}

impl SuggestionState {
    pub fn new(block_id: BlockId, cursor_offset: usize, request_id: u64) -> Self {
        SuggestionState {
            block_id,
            cursor_offset,
            accumulated_text: String::new(),
            is_complete: false,
            request_id,
        }
    }

    /// Добавить chunk от провайдера
    pub fn append_chunk(&mut self, chunk: &AiChunk) {
        self.accumulated_text.push_str(&chunk.delta);
        if chunk.finish_reason.is_some() {
            self.is_complete = true;
        }
    }

    /// Сгенерировать Decoration для отображения ghost text
    pub fn to_decoration(&self) -> Decoration {
        Decoration {
            decoration_type: DecorationType::GhostText,
            block_id: self.block_id.clone(),
            from: self.cursor_offset,
            to: self.cursor_offset,
            attrs: vec![
                ("text".into(), self.accumulated_text.clone().into()),
                ("complete".into(), self.is_complete.into()),
            ].into_iter().collect(),
        }
    }

    /// Принять suggestion — вернуть текст для вставки
    pub fn accept(&self) -> Option<(BlockId, usize, String)> {
        if self.accumulated_text.is_empty() {
            return None;
        }
        Some((
            self.block_id.clone(),
            self.cursor_offset,
            self.accumulated_text.clone(),
        ))
    }
}
```

```typescript
import type { GoTipeEditor } from '@gotipe/core';
import type { AiProvider, AiGenerateParams } from './types/provider';
import { ContextBuilder } from './context-builder';

export interface GhostTextOptions {

  debounce?: number;
  /** Максимальная длина ghost text (символы) */
  maxLength?: number;
  /** Блокировать в code blocks */
  disableInCodeBlocks?: boolean;
  /** Клавиша принятия */
  acceptKey?: string;
  /** Клавиша отклонения */
  rejectKey?: string;
}

export class GhostTextController {
  private provider: AiProvider;
  private contextBuilder: ContextBuilder;
  private editor: GoTipeEditor;
  private options: Required<GhostTextOptions>;
  private abortController: AbortController | null = null;
  private debounceTimer: ReturnType<typeof setTimeout> | null = null;
  private requestId = 0;

  constructor(
    editor: GoTipeEditor,
    provider: AiProvider,
    options: GhostTextOptions = {},
  ) {
    this.editor = editor;
    this.provider = provider;
    this.contextBuilder = new ContextBuilder(editor);
    this.options = {
      debounce: options.debounce ?? 500,
      maxLength: options.maxLength ?? 200,
      disableInCodeBlocks: options.disableInCodeBlocks ?? true,
      acceptKey: options.acceptKey ?? 'Tab',
      rejectKey: options.rejectKey ?? 'Escape',
    };

    this.setupListeners();
  }

  private setupListeners(): void {
    // Trigger ghost text on cursor idle
    this.editor.on('update', () => {
      this.dismiss();
      this.scheduleRequest();
    });

    // Accept / Reject keybindings
    this.editor.on('keydown', (event: KeyboardEvent) => {
      if (event.key === this.options.acceptKey && this.hasActiveSuggestion()) {
        event.preventDefault();
        this.accept();
      }
      if (event.key === this.options.rejectKey && this.hasActiveSuggestion()) {
        event.preventDefault();
        this.dismiss();
      }
    });
  }

  private scheduleRequest(): void {
    if (this.debounceTimer) clearTimeout(this.debounceTimer);

    this.debounceTimer = setTimeout(() => {
      if (this.shouldTrigger()) {
        this.requestSuggestion();
      }
    }, this.options.debounce);
  }

  private shouldTrigger(): boolean {
    const state = this.editor.state;
    const selection = state.selection;

    // Только cursor (не range selection)
    if (!selection.isCursor) return false;

    // Не в code block (если запрещено)
    if (this.options.disableInCodeBlocks) {
      const block = state.doc.getBlock(selection.blockId);
      if (block?.blockType === 'codeBlock') return false;
    }

    // Курсор в конце текста блока
    const block = state.doc.getBlock(selection.blockId);
    if (!block) return false;
    const textLength = block.textContent?.length ?? 0;
    if (selection.offset < textLength) return false;

    // Блок не пустой (минимум 3 символа для контекста)
    if (textLength < 3) return false;

    return true;
  }

  private async requestSuggestion(): Promise<void> {
    // Отменить предыдущий запрос
    this.abortController?.abort();
    this.abortController = new AbortController();

    const currentRequestId = ++this.requestId;
    const state = this.editor.state;
    const selection = state.selection;

    // Собрать контекст через WASM ContextBuilder
    const context = this.contextBuilder.buildInlineContext(state);

    const params: AiGenerateParams = {
      messages: context.messages,
      maxTokens: 128,
      temperature: 0.1,
      stopSequences: ['\n\n', '.', '!', '?'],
      mode: 'inline_completion',
    };

    // Создать SuggestionState в WASM
    this.editor.wasmEditor.createSuggestion(
      selection.blockId,
      selection.offset,
      currentRequestId,
    );

    try {
      for await (const chunk of this.provider.generateStream(params)) {
        // Проверить, не устарел ли запрос
        if (this.requestId !== currentRequestId) return;

        // Обновить WASM state
        this.editor.wasmEditor.appendSuggestionChunk(currentRequestId, chunk.delta);

        // Получить decoration и обновить view
        const decoration = this.editor.wasmEditor.getSuggestionDecoration(currentRequestId);
        this.editor.setDecorations('ghost-text', decoration ? [decoration] : []);

        // Лимит длины
        const totalLength = this.editor.wasmEditor.getSuggestionLength(currentRequestId);
        if (totalLength >= this.options.maxLength) break;
      }
    } catch (error) {
      if ((error as any)?.name !== 'AbortError') {
        console.warn('GoTipe AI: ghost text generation failed', error);
      }
    }
  }

  private accept(): void {
    const result = this.editor.wasmEditor.acceptSuggestion();
    if (result) {
      const { blockId, offset, text } = result;
      this.editor.chain()
        .insertTextAt(blockId, offset, text)
        .setSelection(blockId, offset + text.length)
        .run();
    }
    this.editor.setDecorations('ghost-text', []);
  }

  private dismiss(): void {
    this.abortController?.abort();
    this.editor.wasmEditor.clearSuggestion();
    this.editor.setDecorations('ghost-text', []);
  }

  private hasActiveSuggestion(): boolean {
    return this.editor.wasmEditor.hasSuggestion();
  }

  destroy(): void {
    this.dismiss();
    if (this.debounceTimer) clearTimeout(this.debounceTimer);
  }
}
```

### AI Command Executor (TypeScript)

```typescript
// packages/ai/src/command-executor.ts
import type { GoTipeEditor } from '@gotipe/core';
import type { AiProvider, AiGenerateParams, AiChunk } from './types/provider';
import { ContextBuilder } from './context-builder';

export interface AiCommandResult {
  /** Сгенерированный текст (итоговый) */
  text: string;
  /** Streaming callback вызывается на каждый chunk */
  onChunk?: (accumulated: string) => void;
}

export class AiCommandExecutor {
  private provider: AiProvider;
  private contextBuilder: ContextBuilder;
  private editor: GoTipeEditor;

  constructor(editor: GoTipeEditor, provider: AiProvider) {
    this.editor = editor;
    this.provider = provider;
    this.contextBuilder = new ContextBuilder(editor);
  }

  async execute(
    commandId: string,
    extraParams?: Record<string, string>,
    onChunk?: (accumulated: string) => void,
  ): Promise<string> {
    const state = this.editor.state;
    const selection = state.selection;

    // Получить выделенный текст
    const selectedText = state.doc.getTextInRange(
      selection.blockId,
      selection.from,
      selection.to,
    );

    if (!selectedText) {
      throw new Error('No text selected for AI command');
    }

    // Получить определение команды из WASM
    const commandDef = this.editor.wasmEditor.getAiCommand(commandId);
    if (!commandDef) {
      throw new Error(`Unknown AI command: ${commandId}`);
    }

    // Собрать контекст
    const context = this.contextBuilder.buildCommandContext(state, commandDef, {
      text: selectedText,
      ...extraParams,
    });

    const params: AiGenerateParams = {
      messages: context.messages,
      maxTokens: 1024,
      temperature: 0.3,
      stopSequences: [],
      mode: 'command',
    };

    // Streaming generation
    let result = '';
    for await (const chunk of this.provider.generateStream(params)) {
      result += chunk.delta;
      onChunk?.(result);
    }

    return result;
  }

  /** Применить результат команды к документу */
  apply(commandId: string, generatedText: string): void {
    const commandDef = this.editor.wasmEditor.getAiCommand(commandId);
    const selection = this.editor.state.selection;

    switch (commandDef.replaceMode) {
      case 'ReplaceSelection':
        this.editor.chain()
          .deleteRange(selection.blockId, selection.from, selection.to)
          .insertTextAt(selection.blockId, selection.from, generatedText)
          .run();
        break;

      case 'InsertAfter':
        this.editor.chain()
          .insertTextAt(selection.blockId, selection.to, '\n' + generatedText)
          .run();
        break;

      case 'InsertBlockBelow':
        this.editor.chain()
          .insertBlockAfter('paragraph', {}, generatedText)
          .run();
        break;
    }
  }
}
```

```typescript
        baseUrl: options.baseUrl,
        model: options.model,
      });
    default:
      throw new Error(`Unknown AI provider: ${options.provider}`);
  }
```

## Context Builder

ContextBuilder определяет, какие части документа отправляются в LLM. Алгоритм работает в Rust/WASM для максимальной скорости.

### Алгоритм

```
Документ (N блоков)
│
├── Inline Completion Context
│   │
│   ├─ 1. Текущий блок (где курсор)                    [обязательно]
│   ├─ 2. 3 предыдущих блока (для контекста)           [если есть]
│   ├─ 3. Заголовок документа (первый heading)         [если есть]
│   ├─ 4. Ближайший parent heading (секция)            [если есть]
│   └─ 5. Общий бюджет: max 1500 tokens
│
├── Command Context
│   │
│   ├─ 1. Выделенный текст                             [обязательно]
│   ├─ 2. Блок, содержащий выделение                   [обязательно]
│   ├─ 3. 2 блока до и 2 блока после                   [если есть]
│   ├─ 4. Заголовок документа                          [если есть]
│   ├─ 5. Ближайший parent heading                     [если есть]
│   └─ 6. Общий бюджет: max 3000 tokens
│
└── Free Generation Context
    │
    ├─ 1. Весь документ (до бюджета)                   [truncate if needed]
    ├─ 2. Позиция курсора (маркер)
    └─ 3. Общий бюджет: max 8000 tokens
```

### Rust-реализация

```rust
// crates/gotipe-ai/src/context.rs
use gotipe_core::{Document, EditorState, BlockId, Block};
use crate::provider::{AiMessage, AiRole, AiMode};
use crate::commands::AiCommandDef;

/// Результат сборки контекста
pub struct AiContext {
    pub messages: Vec<AiMessage>,
    pub estimated_tokens: usize,
}

pub struct ContextBuilder {
    /// Максимум tokens для inline completion
    inline_budget: usize,
    /// Максимум tokens для command
    command_budget: usize,
}

impl ContextBuilder {
    pub fn new() -> Self {
        ContextBuilder {
            inline_budget: 1500,
            command_budget: 3000,
        }
    }

    /// Собрать контекст для inline completion (ghost text)
    pub fn build_inline_context(&self, state: &EditorState) -> AiContext {
        let doc = state.doc();
        let selection = state.selection();
        let current_block_id = selection.block_id();

        let mut context_parts: Vec<String> = Vec::new();
        let mut token_count = 0;

        // 1. Заголовок документа
        if let Some(title) = self.find_document_title(doc) {
            let title_text = format!("Document: {}", title);
            token_count += estimate_tokens(&title_text);
            context_parts.push(title_text);
        }

        // 2. Ближайший parent heading
        if let Some(section_heading) = self.find_nearest_heading(doc, current_block_id) {
            let heading_text = format!("Section: {}", section_heading);
            token_count += estimate_tokens(&heading_text);
            context_parts.push(heading_text);
        }

        // 3. Предыдущие блоки (до 3)
        let prev_blocks = self.get_preceding_blocks(doc, current_block_id, 3);
        for block in &prev_blocks {
            let text = block.text_content();
            let tokens = estimate_tokens(&text);
            if token_count + tokens > self.inline_budget {
                break;
            }
            token_count += tokens;
            context_parts.push(text);
        }

        // 4. Текущий блок (текст до курсора)
        if let Some(current_block) = doc.get_block(current_block_id) {
            let full_text = current_block.text_content();
            let text_before_cursor = &full_text[..selection.offset().min(full_text.len())];
            context_parts.push(text_before_cursor.to_string());
        }

        let user_content = context_parts.join("\n");

        AiContext {
            messages: vec![
                AiMessage {
                    role: AiRole::System,
                    content: "You are a writing assistant. Continue the text naturally. \
                        Output only the continuation, no explanations or prefixes. \
                        Match the language, style, and tone of the existing text. \
                        Keep it concise (1-2 sentences max).".into(),
                },
                AiMessage {
                    role: AiRole::User,
                    content: user_content,
                },
            ],
            estimated_tokens: token_count,
        }
    }

    /// Собрать контекст для AI command (rewrite, expand, etc.)
    pub fn build_command_context(
        &self,
        state: &EditorState,
        command: &AiCommandDef,
        params: &std::collections::HashMap<String, String>,
    ) -> AiContext {
        let doc = state.doc();
        let selection = state.selection();
        let selected_text = params.get("text").cloned().unwrap_or_default();

        let mut surrounding_context = String::new();
        let mut token_count = 0;

        // 1. Заголовок документа
        if let Some(title) = self.find_document_title(doc) {
            surrounding_context.push_str(&format!("[Document: {}]\n", title));
        }

        // 2. Окружающие блоки (2 до, 2 после)
        let prev = self.get_preceding_blocks(doc, selection.block_id(), 2);
        let next = self.get_following_blocks(doc, selection.block_id(), 2);

        for block in &prev {
            let text = block.text_content();
            surrounding_context.push_str(&text);
            surrounding_context.push('\n');
        }
        surrounding_context.push_str("---\n"); // marker
        for block in &next {
            let text = block.text_content();
            surrounding_context.push_str(&text);
            surrounding_context.push('\n');
        }

        // 3. Подставить параметры в template
        let mut user_prompt = command.user_prompt_template.clone();
        for (key, value) in params {
            user_prompt = user_prompt.replace(&format!("{{{}}}", key), value);
        }

        token_count = estimate_tokens(&surrounding_context) + estimate_tokens(&user_prompt);

        let system_content = if surrounding_context.is_empty() {
            command.system_prompt.clone()
        } else {
            format!(
                "{}\n\nContext from surrounding document:\n{}",
                command.system_prompt, surrounding_context
            )
        };

        AiContext {
            messages: vec![
                AiMessage {
                    role: AiRole::System,
                    content: system_content,
                },
                AiMessage {
                    role: AiRole::User,
                    content: user_prompt,
                },
            ],
            estimated_tokens: token_count,
        }
    }

    fn find_document_title(&self, doc: &Document) -> Option<String> {
        doc.blocks.iter()
            .find(|b| b.block_type == "heading")
            .map(|b| b.text_content())
    }

    fn find_nearest_heading(&self, doc: &Document, block_id: &BlockId) -> Option<String> {
        let blocks = &doc.blocks;
        let index = blocks.iter().position(|b| &b.id == block_id)?;

        // Ищем ближайший heading выше текущего блока
        for i in (0..index).rev() {
            if blocks[i].block_type == "heading" {
                return Some(blocks[i].text_content());
            }
        }
        None
    }

    fn get_preceding_blocks(&self, doc: &Document, block_id: &BlockId, count: usize) -> Vec<&Block> {
        let index = doc.blocks.iter()
            .position(|b| &b.id == block_id)
            .unwrap_or(0);

        let start = index.saturating_sub(count);
        doc.blocks[start..index].iter().collect()
    }

    fn get_following_blocks(&self, doc: &Document, block_id: &BlockId, count: usize) -> Vec<&Block> {
        let index = doc.blocks.iter()
            .position(|b| &b.id == block_id)
            .unwrap_or(doc.blocks.len());

        let end = (index + 1 + count).min(doc.blocks.len());
        if index + 1 < doc.blocks.len() {
            doc.blocks[index + 1..end].iter().collect()
        } else {
            vec![]
        }
    }
}

/// Грубая оценка количества tokens (1 token ~ 4 chars для английского)
fn estimate_tokens(text: &str) -> usize {
    text.len() / 4 + 1
}
```

### Что НЕ отправляется в LLM

| Данные | Отправляется? | Причина |
|--------|---------------|---------|
| Текст текущего и соседних блоков | Да | Необходим для генерации |
| Заголовок документа | Да | Контекст темы |
| Форматирование (marks) | Нет | LLM работает с plain text |
| Block IDs | Нет | Внутренние идентификаторы |
| CRDT metadata | Нет | Техническое, не релевантно |
| Другие документы пользователя | Нет | Privacy |
| Комментарии, awareness data | Нет | Не нужно для генерации |
| Содержимое image/embed блоков | Нет | Только текстовый контент |

## Streaming

Все AI-операции в GoTipe работают через streaming. Текст появляется в редакторе по мере генерации, без ожидания полного ответа.

### Протоколы

| Протокол | Используется для | Provider |
|----------|-----------------|----------|
| **SSE (Server-Sent Events)** | Cloud providers | OpenAI, Anthropic, Gemini |
| **NDJSON (Newline-Delimited JSON)** | Self-hosted | Ollama |
| **WebSocket** | GoTipe Cloud AI Proxy | `wss://ai.gotipe.com/ws` |

### SSE-поток (OpenAI формат)

```
POST /v1/chat/completions
Content-Type: application/json
Authorization: Bearer sk-...

{"model":"gpt-4o-mini","messages":[...],"stream":true}

---

HTTP/1.1 200 OK
Content-Type: text/event-stream

data: {"choices":[{"delta":{"content":"The"},"finish_reason":null}]}

data: {"choices":[{"delta":{"content":" quick"},"finish_reason":null}]}

data: {"choices":[{"delta":{"content":" brown"},"finish_reason":null}]}

data: {"choices":[{"delta":{"content":" fox"},"finish_reason":"stop"}]}

data: [DONE]
```

### WebSocket-поток (GoTipe Cloud)

```
CONNECT wss://ai.gotipe.com/ws
Authorization: Bearer gotipe_sk_...

→ {"type":"generate","request_id":"r1","params":{...}}

← {"type":"chunk","request_id":"r1","delta":"The"}
← {"type":"chunk","request_id":"r1","delta":" quick"}
← {"type":"chunk","request_id":"r1","delta":" brown"}
← {"type":"done","request_id":"r1","finish_reason":"stop","usage":{"input":120,"output":3}}
```

WebSocket используется в GoTipe Cloud для снижения latency (нет overhead на TCP handshake при каждом запросе) и мультиплексирования нескольких запросов по одному соединению. Подробности в [10-cloud.md](10-cloud.md).

### Semantic Cache

Cloud AI proxy кэширует похожие запросы. Если пользователь запрашивает rewrite текста, близкого к уже обработанному — результат возвращается из кэша без обращения к LLM.

```
Request → Embed (text-embedding-3-small) → Vector search в Valkey
    │
    ├── Hit (cosine similarity > 0.95) → Return cached result (~5ms)
    │
    └── Miss → Forward to LLM provider → Cache result → Return
```

Cache hit rate на реальных данных: ~15-25% для AI commands, ~5-10% для ghost text.

## Privacy

| Режим | Данные покидают машину? | Куда уходят? | Кому подходит |
|-------|------------------------|-------------|---------------|
| **Self-hosted (Ollama)** | Нет | Никуда — всё локально | Медицина, юриспруденция, NDA, paranoid mode |
| **Self-hosted proxy + Cloud LLM** | Да, к LLM провайдеру | OpenAI/Anthropic API | Контроль над proxy, но LLM в облаке |
| **GoTipe Cloud** | Да, к GoTipe Cloud → LLM | GoTipe proxy → OpenAI/Anthropic | Максимум удобства, минимум настройки |

### Self-hosted: zero data leakage

При использовании Ollama:

1. Данные не отправляются ни на какой внешний сервер
2. Модель работает на машине пользователя (или в VPN/корпоративной сети)
3. Нет telemetry, analytics, logging со стороны GoTipe
4. AI layer в WASM core не имеет side effects — `ContextBuilder` только формирует prompt, не отправляет его

```typescript
  async healthCheck() {
    await fetch('https://my-llm.internal/health');
  },
};

const editor = createEditor({
  extensions: [
    ...DefaultPreset,
    AIInline.configure({ provider: myProvider }),
  ],
});
```
