# 24 — What the documentation found

2026-11-12, `main` after 940483f. Five agents wrote the public documentation
(`docs-site/`, 56 pages) and checked every name, parameter and limit against the code. Where
the code behaves differently from what the API, contracts or interface promise, the page states
the limitation openly (the Limitations section), and the defect is recorded here. Tests did not
catch these places. After a fix, update the documentation page too.

Severity: **B** blocks the release (breaks the main scenario, loses data,
opens an attack, or prevents running your own server); **H** is a visible bug or an engine
divergence; **L** is minor or cleanup.
