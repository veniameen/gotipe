# 23 — GoTipe против Tiptap: что есть, чего нет, что делать

Состояние на 2026-11-12. Tiptap смотрели на живых tiptap.dev и tiptap.dev/docs,
GoTipe — по коду `main` (c45dd4c). Полная выписка по Tiptap со ссылками лежит
локально: `output/research/tiptap-inventory-20261112.md` (вне Git).

## Tiptap сейчас

- Версия 3.33 (3.0 вышла в июле 2025). Под капотом ProseMirror и Yjs; сервер
  совместной работы — Hocuspocus 4.8 (Node, Bun, Deno, Workers). 39 тыс. звёзд,
  около 770 открытых issues.
- Позиционирование сместилось вверх: не «headless-редактор», а «инфраструктура
  документов для регулируемых отраслей». Главная страница продаёт SOC 2, HIPAA,
  размещение в ЕС и on-prem, Word-совместимость и правки ИИ на проверке.
- Открыто (MIT): ядро, около 71 расширения, Markdown (с пометкой «early release»),
  static renderer, Hocuspocus, Find & Replace, простой шаблон.
- Платно: всё, что хранится в их облаке (комментарии, история, webhooks), пакеты
  `@tiptap-pro/*` из закрытого реестра и Notion-подобный UI (slash-меню, меню
  ручки, «превратить в»). Отдельные надстройки: Tracked Changes от $249/мес,
  Compare от $3 299/мес, AI Toolkit — через отдел продаж.
- Тарифы считаются по документам: Start $49, Team $149, Business $999 в месяц;
  при превышении тариф повышается автоматически. Бесплатного облака нет с июня 2025.
- Документация — около 790 страниц: демо с вкладками React/Vue на каждой странице
  расширения, «Copy markdown», «Ask AI» (открывает внешние чаты), поиск по ⌘K,
  llms.txt, каждая страница доступна как `.md`. Официального MCP-сервера нет.
- UI-компоненты только для React, раздаются исходниками через CLI, как shadcn.

## Где мы уже сильнее

1. **Всё, за что Tiptap берёт деньги, у нас MIT**: совместная работа, отслеживание
   правок, версии и сравнение, экспорт PDF и DOCX, слой ИИ. Коммерческий только
   готовый UI.
2. **Свой движок.** Лучшие их баги — от ProseMirror: Backspace в списках (#2493,
   #3367, с 2022), IME в Safari и CJK (#7186, #4499), дубли версий (#577). У нас
   выделение, IME и списки свои и проверены в Chromium, Firefox и WebKit.
3. **Markdown без потерь.** У них «early release» с ошибками экранирования (#8471)
   и мягких переносов (#8136); у нас правка абзаца не переписывает остальной файл.
4. **Свой сервер без счёта за документы.** Нет автоповышения тарифа и привязки к их
   облаку: Cloud запускается у клиента одним Docker Compose.
5. **Стабильные имена.** У Tiptap ИИ-продукты переименовывались трижды, Snapshot
   Compare заменён Compare, страница roadmap устарела.

## Чего не хватает

**P0 — без этого не конкурировать:**
- **Inline-узлы в модели.** Блок хранит только `TextSpan[]`, поэтому невозможны
  упоминания, формулы в строке, эмодзи как узел и картинки в тексте. Это решение
  на уровне ядра, JS и Rust вместе — нужен ADR до любых «упоминаний».
- **Публичная документация и сайт** — в работе (`docs-site/`, кадры 20–21 Атласа).
- **Рендер для Svelte, Solid и vanilla.** Ядро не рисует DOM; без React или Vue
  блоки рисует сам хост. У Tiptap есть vanilla и Svelte.
- **Условия коммерческой лицензии.** `LICENSE-COMMERCIAL` — заглушка с адресом;
  `packages/theme/src/base.css` помечен как MIT, хотя пакет коммерческий.

**P1 — что ждут от редактора:**
- Небольшие расширения: поиск и замена, счётчик символов и слов, выравнивание
  текста, типографика (кавычки, тире), автоссылки, вставка Markdown из буфера,
  оглавление как блок, пустой абзац в конце документа.
- Таблицы: объединение и разделение ячеек в UI.
- Синхронизация комментариев и предложений между людьми; хранение версий и
  готовый UI истории в библиотеке.
- Совместная работа в PageEditor (сейчас только JS-движок).
- ИИ-агент с инструментами: читать документ и предлагать правки на проверку.
  Основа уже есть — якорные правки (`applyAnchoredEdits`) и слой ревью PageEditor.
- Импорт DOCX; очистка вставки из Word и Google Docs (у Tiptap — тариф Team).
- Формулы: подключаемый рендер TeX; встраивания с iframe по списку разрешённых
  хостов; аудио и видео.

**P2 — позже:**
- Вид страниц с пагинацией, колонтитулами и сносками.
- Angular, Web Components, мост для мобильных WebView.
- CLI, который кладёт UI-компоненты исходниками в проект.
- Mermaid-диаграммы, ODT и EPUB.

## Что взять в подаче

- **Главная:** живой редактор в первом экране с вкладками (BlockEditor, PageEditor,
  виды); карточки возможностей с бейджами MIT и Commercial — как их Free и Paid;
  проверяемые факты вместо логотипов клиентов; три способа запуска (браузер, WASM,
  свой сервер).
- **Документация:** страница расширения в одном порядке — демо, установка,
  параметры, команды, клавиши, Markdown, ограничения; «Copy Markdown» и `.md` у
  каждой страницы; llms.txt; поиск по ⌘K; prev/next; «Edit on GitHub».
- **Обгоняем:** официальный MCP-сервер документации (у Tiptap его нет); документация
  рисуется самим GoTipe в виде `docs`; живые демо — из playground.
- **Не берём:** счёт за документы, автоповышение тарифа, закрытый реестр пакетов,
  платный Notion-подобный UI поверх открытого ядра.

## Порядок работ

1. Сайт и документация: кадры 20–21 Атласа → решение владельца → `apps/landing`.
2. ADR по inline-узлам (JS, Rust, CRDT, Markdown), затем упоминания и формулы в строке.
3. Пакет небольших расширений из P1.
4. Синхронизация комментариев и предложений, хранение версий, UI истории.
5. ИИ-агент с инструментами поверх якорных правок.
6. Рендер для Svelte, Solid и vanilla.
7. Импорт DOCX и очистка вставки.
