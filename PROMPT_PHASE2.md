# GoTipe — Промт для реализации Фазы 2 (TypeScript Packages)

## Контекст

Ты продолжаешь реализацию GoTipe. Фаза 1 (Rust workspace: 8 crates + root config) уже готова. Теперь — Фаза 2: 19 TypeScript packages. Каждый файл должен быть **полностью рабочим** — компилироваться, проходить тесты, содержать полные типы и реализации. Не заглушки.

**Предпосылки:** WASM crate (`gotipe-wasm`) уже собран и лежит в `packages/wasm/pkg/`. Все Rust crates компилируются и проходят тесты.

## Обязательные правила

1. **WASM owns state:** EditorState живёт в Rust/WASM. JS получает ViewState (plain objects). Изменения ТОЛЬКО через `dispatch(Transaction)` — никогда не мутировать state из JS
2. **Extension = всё:** Каждый block type, mark, behavior — extension. API: `defineExtension()`. Не создавать блоки/marks вне extension system
3. **Factory pattern:** `createEditor(options)` (НЕ `new Editor()`). Chainable: `editor.chain().toggleBold().run()`
4. **Conditional exports:** `"types"` ВСЕГДА первым в package.json exports → `import` → `require`
5. **CSS tokens:** Переменные `--gt-*` (НЕ `--gotipe-*`). Классы `.gotipe-*`
6. **Lazy loading:** PDF ~400KB и DOCX ~60KB — lazy `import()`. Не бандлить в core
7. **HTML sanitization:** WASM ammonia → JS DOMPurify fallback. Никогда `dangerouslySetInnerHTML` без sanitization
8. **НЕ использовать Yjs** — GoTipe имеет собственный CRDT
9. **НЕ добавлять runtime deps в MIT packages, если нужны только для commercial block-editor**
10. **Build:** tsup (ESM + CJS), `"sideEffects": false`, entry = `src/index.ts`
11. **Tests:** Vitest, `describe/it`, mock WASM через `vi.mock`
12. **Ошибки:** `GoTipeError` с typed `code` для pattern matching
13. **Adapters:** React = `useSyncExternalStore`, Vue = `shallowRef + triggerRef`, Svelte 5 = `$state`, Solid = `createSignal`

```typescript
/**
 * Factory function — единственный способ создать editor.
 * Инициализирует WASM, строит schema из extensions, создаёт EditorState.
 */
export async function createEditor(options: CreateEditorOptions): Promise<GoTipeEditor> {
  // 1. Initialize WASM bridge
  const bridge = new WasmBridge();
  await bridge.init();

  // 2. Resolve extension dependencies (topological sort, circular dependency detection)
  const resolved = resolveExtensions(options.extensions);

  // 3. Build schema from extensions (merge all nodes + marks)
  const schema = buildSchema(resolved);

  // 4. Create WasmEditor with schema + initial content
  const initialContent = options.content
    ? (typeof options.content === 'string'
        ? { blocks: [], version: 1 } // parse HTML/MD later
        : options.content)
    : { blocks: [{ id: generateBlockId(), type: 'paragraph', attrs: {}, content: [], children: [] }], version: 1 };

  bridge.create(JSON.stringify(schema), JSON.stringify(initialContent));

  // 5. Build GoTipeEditor instance
  // ... full implementation: event emitter, chain commands, ViewState generation, mount/unmount
  // ... lifecycle hooks: call onCreate on each extension in dependency order
  // ... on destroy: call onDestroy in reverse order
}
```

Полная реализация `createEditor` включает:
- Event emitter pattern (`on`, `off`, `emit`) через Map<string, Set<Function>>
- `getViewState()` → вызывает `bridge.getState()`, парсит JSON в ViewState
- `chain()` → возвращает `new ChainableCommands(editor)` с fluent API
- `dispatch(tr)` → вызывает `bridge.apply(JSON.stringify(tr))`, обновляет ViewState, emits 'update'
- `mount(element)` → рендерит blocks в DOM, подключает DOM event listeners (input, keydown, paste, copy, cut, compositionstart/end, selectionchange), обновляет DOM при ViewState changes
- `destroy()` → calls `onDestroy` на каждом extension в обратном порядке, removes DOM listeners, destroys WASM instance
- Extension lifecycle: `onCreate` вызывается в dependency order после инициализации, `onUpdate` после каждого dispatch

### `packages/core/src/wasm-bridge.ts`

```typescript
import init, { WasmEditor } from '@gotipe/wasm';

export class WasmBridge {
  private editor: WasmEditor | null = null;
  private initialized = false;

  async init(): Promise<void> {
    if (this.initialized) return;
    try {
      await init();
      this.initialized = true;
    } catch (e) {
      // Graceful degradation: если WASM не доступен (CSP, unsupported browser),
      // используем JS fallback для базовых операций (validate, parse)
      console.warn('GoTipe WASM init failed, using JS fallback:', e);
      this.initialized = true; // mark as initialized to avoid retry loops
    }
  }

  create(schemaJson: string, docJson: string): void {
    this.editor = new WasmEditor(schemaJson, docJson);
  }

  apply(transactionJson: string): string {
    if (!this.editor) throw new GoTipeError('Editor not initialized');
    return this.editor.apply(transactionJson);
  }

  validate(docJson: string): boolean {
    if (!this.editor) return true;
    return this.editor.validate(docJson);
  }

  getState(): string {
    if (!this.editor) throw new GoTipeError('Editor not initialized');
    return this.editor.export_json();
  }

  exportHtml(): string { return this.editor!.export_html(); }
  exportMarkdown(): string { return this.editor!.export_markdown(); }
  sanitizeHtml(html: string): string { return this.editor!.sanitize_html(html); }

  // Collaboration
  enableCollaboration(peerId: string): void { this.editor!.enable_collaboration(peerId); }
  receiveUpdate(binary: Uint8Array): string { return this.editor!.receive_update(binary); }
  getUpdate(): Uint8Array { return this.editor!.get_update(); }

  // Comments
  addComment(json: string): string { return this.editor!.add_comment(json); }
  resolveComment(id: string): void { this.editor!.resolve_comment(id); }
  getComments(): string { return this.editor!.get_comments(); }

  // Versions
  createVersion(name: string): string { return this.editor!.create_version(name); }
  listVersions(): string { return this.editor!.list_versions(); }
  restoreVersion(id: string): string { return this.editor!.restore_version(id); }

  // AI
  detectPii(text: string): string { return this.editor!.detect_pii(text); }

  destroy(): void {
    this.editor = null;
  }
}
```

```typescript
export type FocusRegion =
  | 'skip-nav' | 'toolbar' | 'editor' | 'slash-menu'
  | 'bubble-menu' | 'link-dialog' | 'footer';

export class FocusManager {
  private regions = new Map<FocusRegion, HTMLElement>();
  private focusStack: HTMLElement[] = [];

  register(region: FocusRegion, element: HTMLElement): void {
    this.regions.set(region, element);
    element.setAttribute('data-gotipe-region', region);
  }

  unregister(region: FocusRegion): void {
    this.regions.delete(region);
  }

  focusRegion(region: FocusRegion): void {
    const el = this.regions.get(region);
    if (el) {
      this.focusStack.push(document.activeElement as HTMLElement);
      el.focus();
    }
  }

  restoreFocus(): void {
    const prev = this.focusStack.pop();
    if (prev?.isConnected) prev.focus();
  }

  trapFocusIn(container: HTMLElement): () => void {
    const focusable = container.querySelectorAll<HTMLElement>(
      'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
    );
    const first = focusable[0];
    const last = focusable[focusable.length - 1];

    const handler = (e: KeyboardEvent) => {
      if (e.key !== 'Tab') return;
      if (e.shiftKey && document.activeElement === first) {
        e.preventDefault();
        last?.focus();
      } else if (!e.shiftKey && document.activeElement === last) {
        e.preventDefault();
        first?.focus();
      }
    };

    container.addEventListener('keydown', handler);
    first?.focus();
    return () => container.removeEventListener('keydown', handler);
  }
}
```

```typescript
export const SANITIZER_CONFIG = {
  allowedElements: [
    'p', 'h1', 'h2', 'h3', 'h4', 'h5', 'h6',
    'ul', 'ol', 'li', 'blockquote', 'pre', 'code',
    'strong', 'em', 'u', 's', 'del', 'mark', 'a',
    'sup', 'sub', 'br', 'hr', 'img', 'table', 'thead',
    'tbody', 'tr', 'th', 'td', 'figure', 'figcaption',
    'details', 'summary', 'span', 'div',
  ],
  allowedAttributes: {
    a: ['href', 'target', 'rel'],
    img: ['src', 'alt', 'width', 'height'],
    td: ['colspan', 'rowspan'],
    th: ['colspan', 'rowspan'],
    code: ['class'], // for language class
    '*': ['class', 'id'],
  },
  allowedSchemes: ['http', 'https', 'mailto'],
};

/**
 * Sanitize HTML: WASM ammonia (primary) + DOMPurify (fallback)
 */
export function sanitizeHtml(html: string, bridge?: { sanitizeHtml: (h: string) => string }): string {
  // 1. Try WASM sanitizer (ammonia in Rust)
  if (bridge) {
    try {
      return bridge.sanitizeHtml(html);
    } catch {
      // Fall through to DOMPurify
    }
  }

  // 2. DOMPurify fallback (lazy loaded)
  // Note: DOMPurify is NOT a dependency — it should be provided by the consumer
  // or we use a minimal built-in sanitizer based on browser DOMParser
  return sanitizeWithDOMParser(html);
}

function sanitizeWithDOMParser(html: string): string {
  const doc = new DOMParser().parseFromString(html, 'text/html');
  // Walk DOM tree, remove elements not in allowlist, remove attrs not in allowlist
  // Block javascript:, data: URIs in href/src
  // Return sanitized innerHTML
  const walker = doc.createTreeWalker(doc.body, NodeFilter.SHOW_ELEMENT);
  const toRemove: Element[] = [];

  let node: Node | null = walker.currentNode;
  while (node) {
    if (node instanceof Element) {
      const tag = node.tagName.toLowerCase();
      if (!SANITIZER_CONFIG.allowedElements.includes(tag)) {
        toRemove.push(node);
      } else {
        // Remove disallowed attributes
        for (const attr of Array.from(node.attributes)) {
          const allowed = SANITIZER_CONFIG.allowedAttributes[tag] ?? SANITIZER_CONFIG.allowedAttributes['*'] ?? [];
          if (!allowed.includes(attr.name)) {
            node.removeAttribute(attr.name);
          }
          // Block dangerous URIs
          if ((attr.name === 'href' || attr.name === 'src') && /^(javascript|data|vbscript):/i.test(attr.value)) {
            node.removeAttribute(attr.name);
          }
        }
      }
    }
    node = walker.nextNode();
  }

  for (const el of toRemove) {
    el.parentNode?.replaceChild(
      document.createTextNode(el.textContent || ''),
      el,
    );
  }

  return doc.body.innerHTML;
}
```

```typescript
import type { BlockView } from './types/view';

const ACTIVATION_THRESHOLD = 500; // blocks

export interface VisibleRange {
  startIndex: number;
  endIndex: number;
  overscan: number;
}

/**
 * Compute visible block range for documents >500 blocks.
 * Uses intersection observer + scroll position for windowed rendering.
 */
export function computeVisibleRange(
  blocks: BlockView[],
  scrollTop: number,
  containerHeight: number,
  estimatedBlockHeight: number,
): VisibleRange | null {
  if (blocks.length < ACTIVATION_THRESHOLD) return null; // render all

  const overscan = 10; // extra blocks above/below viewport
  const startIndex = Math.max(0, Math.floor(scrollTop / estimatedBlockHeight) - overscan);
  const visibleCount = Math.ceil(containerHeight / estimatedBlockHeight) + overscan * 2;
  const endIndex = Math.min(blocks.length - 1, startIndex + visibleCount);

  return { startIndex, endIndex, overscan };
}
```

```typescript
    return () => {
      destroyed = true;
      instance?.destroy();

  }, []); // intentionally empty deps — editor created once
```

```tsx
import React, { useRef, useEffect, useState } from 'react';
import type { GoTipeEditor } from '@gotipe/core';
import type { ViewState } from '@gotipe/core';

export interface BubbleMenuProps {
  editor: GoTipeEditor;
  shouldShow?: (props: { editor: GoTipeEditor; state: ViewState }) => boolean;
  offset?: { x: number; y: number };
  children: (props: { editor: GoTipeEditor }) => React.ReactNode;
}

export function BubbleMenu({ editor, shouldShow, offset, children }: BubbleMenuProps) {
  const [visible, setVisible] = useState(false);
  const [position, setPosition] = useState({ top: 0, left: 0 });
  const menuRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const unsub = editor.on('selectionChange', () => {
      const state = editor.getViewState();
      const show = shouldShow
        ? shouldShow({ editor, state })
        : state.selection.type === 'text';

      setVisible(show);
      if (show) {
        // Position relative to browser Selection
        const sel = window.getSelection();
        if (sel && sel.rangeCount > 0) {
          const rect = sel.getRangeAt(0).getBoundingClientRect();
          setPosition({
            top: rect.top - (menuRef.current?.offsetHeight ?? 0) - 8 + (offset?.y ?? 0),
            left: rect.left + rect.width / 2 - (menuRef.current?.offsetWidth ?? 0) / 2 + (offset?.x ?? 0),
          });
        }
      }
    });
    return unsub;
  }, [editor, shouldShow, offset]);

  if (!visible) return null;

  return (
    <div
      ref={menuRef}
      className="gotipe-bubble-menu"
      role="toolbar"
      aria-label="Text formatting"
      style={{
        position: 'fixed',
        top: `${position.top}px`,
        left: `${position.left}px`,
        zIndex: 'var(--gt-z-bubble, 40)' as any,
      }}
    >
      {children({ editor })}
    </div>
  );
}
```

## Подсказки по реализации

1. **WASM mock в тестах:** Используй `vi.mock('@gotipe/wasm', () => ({ default: vi.fn(), WasmEditor: vi.fn() }))`. Stub WasmEditor methods: `apply() → '{"blocks":[]}'`, `export_json() → '...'`, `validate() → true`.

2. **Extension dependency resolution:** Topological sort (Kahn's algorithm). Detect cycles: if remaining extensions after sort ≠ 0, there's a cycle → throw GoTipeError('EXTENSION_DEPENDENCY_CYCLE').

3. **ViewState generation:** Core получает raw JSON от WASM, парсит в ViewState. ToolbarState вычисляется из Selection + Document (какие marks в текущем selection, какой block type).

4. **DOM rendering в mount():** Render blocks как DOM nodes с `contentEditable`. Каждый block = `<div data-gotipe-block={type} data-block-id={id}>`. RichText = `<span>` elements с mark classes (`.gotipe-mark-bold`, etc.). Input events → parse DOM changes → create Steps → dispatch.

5. **BubbleMenu positioning:** Используй `window.getSelection().getRangeAt(0).getBoundingClientRect()` для position. Clamp к viewport: если menu выходит за edge, прижми с padding 8px.

6. **SSE streaming для AI:** Используй `fetch()` + `ReadableStream`. Парсинг: split by `\n`, filter `data:` prefix, parse JSON chunks. Handle `[DONE]` sentinel.

7. **i18n ICU MessageFormat:** Для pluralization используй паттерн `{count, plural, one {# item} other {# items}}`. Для select: `{gender, select, male {He} female {She} other {They}}`.

8. **Theme prefers-color-scheme:** В tokens.css: `@media (prefers-color-scheme: dark) { :root { --gt-bg: #191919; ... } }`. Data attribute override: `[data-theme="dark"] { --gt-bg: #191919; }` takes precedence.
