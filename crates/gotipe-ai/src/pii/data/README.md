# Unicode classification data

These are sorted, inclusive Unicode 16.0 scalar ranges encoded as pairs of
little-endian u32 values. They describe Decimal_Number, White_Space and the Unicode
word class used by the previous PII regular expressions. Binary data avoids a
runtime regex compiler or parsing a text table on each detection request.

Data source: the Unicode 16.0 tables generated by ucd-generate 0.3.1 and distributed
in regex-syntax 0.8.9 (`perl_decimal.rs`, `perl_space.rs`, `perl_word.rs`). Its MIT
license is retained here. The scanner and lookup implementation are GoTipe code;
regex remains a development-only differential oracle.

To regenerate, read each source table's `(char, char)` ranges in order, decode Rust
character escapes, then encode each pair using `<II` (little-endian uint32).
No executable code is embedded in these files.
