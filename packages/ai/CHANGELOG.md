# @gotipe/ai

## 0.1.2

### Patch Changes

- A key pressed in a widget inside the text, such as a host's field or a button, is left to that
  widget: Tab there no longer accepts the AI ghost text, and keys there no longer dismiss it. This
  holds for the autocomplete of `@gotipe/ai` and for `AiGhostText` of `@gotipe/ai-ui`.
