# Third-party notices

The PII classifier includes compact Unicode 16.0 character-range data derived
from regex-syntax 0.8.9 (Rust regex project, MIT). GoTipe's scanner is its own
implementation; the regex runtime is not included. The original license is
reproduced in `licenses/pii-unicode-MIT.txt`.

Data source and generation details are maintained in
`crates/gotipe-ai/src/pii/data/README.md` in the GoTipe source distribution.

The Markdown parser's named character reference table matches CPython v3.13.9
`Lib/html/entities.py` (`html5`, trailing semicolons removed from keys), derived
from WHATWG's named references. It contains data, not Python parsing code. The
original Python notices are in `licenses/named-entities-Python-LICENSE.txt`;
provenance is recorded in `packages/markdown/THIRD_PARTY_NOTICES.md` in source.

Original Cargo dependency notices and a version/hash inventory are included in
`licenses/cargo/`, generated by `scripts/collect-rust-licenses.py` from this
module's normal/build dependency graph for wasm32-unknown-unknown.
